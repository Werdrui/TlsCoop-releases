# TLS Coop releases

Downloads for TLS Coop, a mod that adds online co-op for two players to [The Last Spell](https://store.steampowered.com/app/1105670/The_Last_Spell/).

This is a fan project, not affiliated with Ishtar Games or The Arcade Crew. You need your own copy of the game. Both players need the same version of the mod.

## Install

Download from the [latest release](https://github.com/Werdrui/TlsCoop-releases/releases/latest):

- **`TlsCoopSetup.exe`**: finds your game through Steam, then downloads and installs the newest version. Run it again to update. The exe isn't signed, so Windows may show a SmartScreen warning.
- **`TlsCoop_*.zip`**: to install by hand, extract it into the game folder. The zip includes BepInEx 5.

This repository only holds release files. It has no source code.
